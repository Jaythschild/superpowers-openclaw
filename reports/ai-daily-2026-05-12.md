## 1）模型与产品更新

### [模型] OpenAI：GPT‑5.5 Instant 成为 ChatGPT 新默认模型

- **一句话摘要**：OpenAI 发布 GPT‑5.5 Instant，用于替代 GPT‑5.3 Instant 作为 ChatGPT 默认模型。
- **为什么重要**：这不是单纯能力升级，而是默认入口升级；默认模型决定了最大规模用户的体验基线。重点能力包括低延迟、敏感领域少幻觉、数学/多模态基准提升，以及更清晰的记忆来源展示。
- **来源**：TechCrunch 报道；OpenAI 官方 GPT‑5.5 Instant 页面。

### [语音] OpenAI：Realtime API 三个新语音模型

- **一句话摘要**：OpenAI 推出 GPT‑Realtime‑2、GPT‑Realtime‑Translate、GPT‑Realtime‑Whisper。
- **为什么重要**：语音 AI 正从“听懂并回答”升级到“边听边推理、边调用工具、边翻译/转写”。这会直接影响客服、车载、会议、跨语言沟通和实时助手。
- **细节亮点**：GPT‑Realtime‑2 支持更长上下文、并行工具调用、可调 reasoning effort；Translate 支持 70+ 输入语言到 13 种输出语言；Whisper 面向低延迟流式转写。
- **来源**：OpenAI 官方发布。

### [模型] DeepSeek：DeepSeek‑V4 Preview 开源，默认 1M 上下文

- **一句话摘要**：DeepSeek‑V4 Preview 已上线并开源，包含 V4‑Pro 与 V4‑Flash 两条路线。
- **为什么重要**：1M 上下文成为官方服务默认能力，说明长上下文正在从“亮点参数”变成“基础设施能力”。对知识库问答、长文档分析、代码仓库理解、Agent 任务记忆都很关键。
- **来源**：DeepSeek API Docs / Transparency Center。

## 2）智能体 / Agent 动态

### [企业 Agent] OpenAI Deployment Company：OpenAI 把企业部署能力公司化

- **一句话摘要**：OpenAI 成立 OpenAI Deployment Company，并拟收购 Tomoro，获得约 150 名前沿部署工程师与专家。
- **为什么重要**：这说明前沿模型公司正在补齐“最后一公里”：不只是卖 API，而是进入客户核心工作流，帮助企业重构流程、接入数据和工具、形成可持续系统。
- **影响判断**：未来企业 AI 竞争会从“谁的模型更强”转向“谁能更快把模型变成组织生产力”。
- **来源**：OpenAI 官方发布。

### [编码 Agent] OpenAI 披露 Codex 安全运行方法

- **一句话摘要**：OpenAI 介绍了 Codex 在真实工作流中的沙箱、审批、网络访问、身份、规则与遥测日志体系。
- **为什么重要**：编码 Agent 具备执行命令、修改代码、访问工具的能力，安全边界会成为企业采用的前提。可审计、可回滚、可审批，是 Agent 进入生产环境的关键。
- **来源**：OpenAI 官方安全文章。

### [金融 Agent] Anthropic 深化金融行业 Agent 布局

- **一句话摘要**：Axios 报道 Anthropic 正加强华尔街业务，并推出面向金融工作流的 AI Agent。
- **为什么重要**：金融是高价值、高合规、高文档密度场景，适合 Agent 做投行材料、模型、审计与估值分析。谁能在金融场景形成可信工作流，谁就更容易拿下企业级高客单价市场。
- **来源**：Axios。

## 3）开源与研究论文

### [开源] Qwen-Scope：面向 Qwen 的可解释性工具

- **一句话摘要**：阿里云社区发布 Qwen-Scope，用 Sparse Autoencoders 解析 Qwen3 / Qwen3.5 隐层特征。
- **为什么重要**：可解释性会影响模型可控性、安全评估、数据合成和模型优化。随着模型进入企业生产，能解释模型为什么这么做，会越来越值钱。
- **来源**：Alibaba Cloud Community。

### [开源] DeepSeek‑V4 的长上下文与 Agentic Coding

- **一句话摘要**：DeepSeek‑V4 Preview 强调 Token-wise compression + DSA，并在 Agentic Coding 上做专门优化。
- **为什么重要**：开源模型如果在长上下文和 Agentic Coding 上继续逼近闭源模型，会压低智能体开发成本，也会提高本地/私有化部署吸引力。
- **来源**：DeepSeek API Docs。

- **来源**：OpenAI 官方发布。

### [治理] 美国主要 AI 公司同意让 CAISI 做模型预发布测试

- **一句话摘要**：Tom’s Hardware 报道，Google、Microsoft、xAI 等同意让美国商务部下属 CAISI 在模型公开前进行评估；OpenAI、Anthropic 也在相关合作框架中。
- **为什么重要**：预发布评测意味着监管从“出了问题再管”向“模型发布前先测风险”移动。对前沿模型发布节奏、合规成本和国家安全评估都会产生影响。
- **来源**：Tom’s Hardware。

### [竞争] Meta 新模型 Avocado 延期

- **一句话摘要**：Reuters / Yahoo Finance 报道，Meta 将 AI 模型 “Avocado” 推迟到至少 5 月或更晚。
- **为什么重要**：Meta 虽然资本开支巨大，但前沿模型追赶并不稳定。若 Avocado 表现不足，Meta 可能更依赖外部模型或调整路线。
- **来源**：Reuters via Yahoo Finance。
