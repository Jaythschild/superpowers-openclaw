## 今日核心摘要

- **Google 把搜索入口 Agent 化**：Search I/O 2026 的重点是更长查询、对话式搜索、Search agents、agentic booking 和搜索内生成式 mini apps。
- **Gemini Spark 指向 24/7 个人 Agent**：Google 官方称 Spark 会基于 Gemini 3.5 与 Antigravity harness，在 Workspace、Gmail、Docs、Slides 和 MCP 连接器中执行后台任务。
- **Anthropic 正在补企业连接器能力**：收购 Stainless 说明 Claude 平台在 API、SDK、工具连接和开发者体验上继续内收；KPMG 合作则把 Claude 带进漏洞修复、咨询和核心企业流程。
- **OpenAI 强化内容溯源**：OpenAI 宣布 C2PA conformance、引入 Google SynthID 图像水印，并预览公开验证工具，目标是让 AI 图像来源更可验证。
- **AI 编程入口继续迁移到 CLI、移动端和浏览器**：Codex、Claude Code、Gemini CLI、opencode、GitHub Copilot CLI、WebMCP 与 Chrome DevTools for agents 会继续抢开发者注意力。

## Agent / 智能体动态

- Google Search I/O 2026 宣布 Search agents 与 agentic booking，强调搜索将从信息检索变成后台监控和任务执行。
- Gemini Spark 将以 24/7 个人 Agent 的形式进入 Google 生态，并计划连接 Canva、OpenTable、Instacart 等 MCP partner。
- Google Developers I/O 2026 keynote 提到 WebMCP、Modern Web Guidance、Chrome DevTools for agents，说明网页和浏览器正在给 Agent 准备结构化调用边界。
- Anthropic 收购 Stainless，官方重点放在 Claude Platform 的 developer experience 与 agent connectivity。

## 模型与产品

- **Google / Gemini 3.5 Flash**：Google 将 Gemini 3.5 Flash 放到 AI Mode 与 Gemini app 的核心位置，强调快、可行动、适合 Agent 与 Coding。
- **Google / Gemini Spark**：Spark 是今日最重要的个人 Agent 信号，特别是后台运行、Workspace 连接、MCP partner 和高风险动作先询问。
- **Anthropic / Stainless**：Stainless 补的是 API 与 SDK 体验，也是在补 Agent 连接外部系统时的稳定性。
- **Anthropic / KPMG**：KPMG 将 Claude 用于核心业务、客户交付与安全漏洞修复，说明企业 Agent 已从试点进入工作流整合。
- **OpenAI / 内容溯源**：C2PA、SynthID 与公开验证工具预览共同说明，AI 内容可信会成为平台级基础设施，而不是单一检测器问题。

## 开源与研究

- **WebMCP 值得持续跟进**：它试图让网站把函数、表单和任务以可调用方式暴露给浏览器 Agent。纳斯建议把它和 MCP 一起放进 OpenClaw 长期观察清单。
- **Android migration agent 代表高价值工程任务**：Google 预览 Android Studio 迁移 Agent，说明迁移、重构、质量检查会是 Agent 最有商业价值的场景之一。
