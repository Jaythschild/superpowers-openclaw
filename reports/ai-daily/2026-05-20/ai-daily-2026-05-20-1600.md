## Agent / 智能体动态

### 问题 / 背景

- 用户正在从“问 AI 一个答案”转向“让 AI 持续监控、比较、预订、迁移、修复和交付”。
- Agent 一旦能连接搜索、浏览器、Gmail、企业数据、代码仓库和 CLI，真正的难点就变成权限、审计、成本和可回滚。

### 关键变化

- Google Search I/O 2026 宣布 Search agents：可在后台监控 Web、新闻、社交、金融、购物、体育等信号，并在问题发生变化时给用户更新。
- Gemini app 方向变得更主动：Google 官方称 Gemini 将提供 Daily Brief 和 Gemini Spark，作为 24/7 个人 Agent。
- Google 开发者 keynote 提到 WebMCP、Modern Web Guidance、Chrome DevTools for agents，说明浏览器正在为 Agent 暴露结构化工具边界。
- Anthropic 收购 Stainless，官方重点放在 Claude Platform 的 developer experience 和 agent connectivity。

### 影响

- **对产品**：搜索、聊天、浏览器、办公套件都在变成 Agent 控制台。
- **对开发者**：未来网站和工具若想被 Agent 稳定调用，需要更清晰的结构化接口、权限边界和可观测日志。
- **对杰斯 / OpenClaw**：OpenClaw 的关键不是“接入更多工具”本身，而是每个工具都要有权限、撤销、日志、预算和失败处理。

## 模型与产品

- **Google / Gemini 3.5 Flash**：Google 称 Gemini 3.5 Flash 成为 AI Mode 新默认模型，强调其适合 agents 和 coding；Search 内还会结合 Antigravity 与生成式 mini apps。
- **Google / Gemini Spark**：Google 官方博客和 TechCrunch 均提到 Gemini Spark 作为 24/7 agentic assistant，重点在 Gmail、日程、个人上下文与主动任务。
- **Anthropic / Stainless**：收购 Stainless 的意义是把 API SDK、工具连接和 Agent 平台体验向 Claude 平台内收。
- **Anthropic / KPMG**：KPMG 与 Anthropic 扩大战略合作，KPMG 将把 Claude 用于核心业务、客户交付与安全漏洞修复。
- **OpenAI / 内容溯源**：OpenAI 推 C2PA、SynthID 和公开验证工具预览，方向是让 AI 图像来源更容易被平台和公众识别。

## 开源与研究

- **WebMCP 值得跟进**：它试图让网站把函数、表单和任务以更可调用的方式暴露给浏览器 Agent。后续要重点观察它和 MCP 的接口边界、权限模型和浏览器实现。
- **Android migration agent 是高价值工程场景**：Google 预览 Android Studio 迁移 Agent，可把 React Native、Web 或 iOS 代码迁移到 Kotlin Android 应用。迁移、重构、质量检查会是 Agent 最有价值的工程任务之一。
- **OverEager-Bench 提醒 Agent 安全不能只看成功率**：论文测试 Claude Code、OpenHands、Codex CLI、Gemini CLI 等 Agent 在良性任务中的越界行为，说明“做得太多”本身就是风险。

## 纳斯观察

今天最重要的判断：**Agent 竞争正在从“谁模型更强”转向“谁拥有入口、连接器、信任机制和成本控制”。**

Google 在抢搜索和浏览器入口，Anthropic 在补企业连接器和平台体验，OpenAI 在补内容可信与治理标准。对杰斯来说，最值得落地的是把 OpenClaw 的自动化做成四层：能连接、能审计、能控成本、能回滚。否则 Agent 越能干，系统风险也越大。
