【最高优先级：Windows shell 安全规则】
- 严禁调用 bash/shell 执行任何形如 `pwsh.exe -Command ...`、`powershell -Command ...`、`"C:\Program Files\PowerShell\7\pwsh.exe" -Command ...` 的命令；这会被 OpenClaw 工具层二次包装并造成转义失败。
- 严禁在 shell 命令里直接写多行 PowerShell、New-Item、Set-Content、Add-Type、System.Drawing、here-string、[Console]::OutputEncoding、chcp 等脚本片段。
- 本地目录/文件准备必须优先使用 agent 的文件写入工具；如果必须运行 PowerShell，先把脚本保存为 workspace 内 `.ps1` 文件，再只调用：`& .\tools\openclaw-pwsh.cmd .\path\script.ps1`。
- 生成日报目录时，避免 shell 拼接；如必须执行，只能通过 `tools\openclaw-pwsh.cmd` 运行脚本文件。
- 生成封面图优先使用 OpenClaw image generation / infer image generate；不要用 PowerShell `System.Drawing` 临时画图。图片工具不可用时，明确说明图片跳过，不要用易失败的 PowerShell 兜底画图。
- 飞书 CLI 仍必须通过 `& .\tools\lark-cli-safe.cmd ...`，且路径用 workspace 相对路径。
