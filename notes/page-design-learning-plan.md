# 页面美化与设计学习计划

## 学习目标

让纳斯在网页、后台系统、落地页、演示页、控制台 UI 等场景中，能够做到：

- 快速判断页面“不好看”的原因
- 给出清晰的美化方案
- 能直接改代码、调样式、做视觉优化
- 能用截图验证效果
- 形成稳定的设计审美和执行流程

## 阶段 1：设计基础认知（第 1-3 天）

重点学习：

- 视觉层级：标题、正文、按钮、卡片的优先级
- 留白系统：8px 栅格、区块间距、卡片内边距
- 字体排版：字号、字重、行高、对齐方式
- 色彩基础：主色、辅助色、中性色、状态色
- 对比度与可读性

练习方式：

- 每天分析 3 个优秀页面
- 总结它们的布局、配色、字体、间距
- 记录“为什么它看起来高级”

产出：

- 页面美化检查清单 v1
- 常用间距/字号/圆角规范

## 阶段 2：常见 UI 风格库（第 4-7 天）

重点学习不同风格：

- 极简科技风
- 苹果官网风
- SaaS 后台风
- 商务官网风
- AI 产品落地页风
- 玻璃拟态 / 卡片式 / 暗色科技风

练习方式：

- 每种风格整理一套设计关键词
- 总结配色、背景、卡片、按钮、动效特征
- 为每种风格写一个可复用 prompt / CSS 模板

产出：

- `style-recipes.md`：页面风格配方库

## 阶段 3：前端实现能力（第 2 周）

重点学习：

- CSS Grid / Flex 布局
- 响应式设计
- Tailwind 常用美化套路
- 渐变、阴影、圆角、毛玻璃、背景纹理
- Hover / transition / keyframe 动效
- 深色模式设计

练习方式：

- 找 3 个普通页面，重构成高级视觉版本
- 每次都截图前后对比
- 总结可复用组件样式

产出：

- `ui-snippets.md`：常用 CSS / Tailwind 片段库
- `before-after/`：页面美化案例库

## 阶段 4：真实页面改造流程（第 3 周）

建立固定工作流：

1. 看页面目标：它要卖什么、展示什么、引导什么
2. 找视觉问题：乱、挤、灰、弱、没重点、不统一
3. 定风格方向：科技 / 商务 / 极简 / 活泼 / 高端
4. 改结构：先布局和层级
5. 改视觉：颜色、字体、卡片、图标、图片
6. 加细节：动效、状态、响应式
7. 截图验收：桌面端 + 移动端

产出：

- `page-polish-workflow.md`：页面美化 SOP

## 阶段 5：审美积累与素材库（长期）

持续积累：

- 优秀页面截图
- 配色方案
- 字体组合
- Landing Page 结构
- Dashboard 组件
- 卡片样式
- Hero 区设计
- CTA 按钮设计
- 空状态 / 加载状态 / 错误状态设计

产出：

- `design-inspiration.md`：灵感库
- `design-system-notes.md`：设计系统笔记

## 每日学习节奏

每天 30-45 分钟：

- 10 分钟：看优秀案例
- 10 分钟：拆解设计原因
- 15-20 分钟：做一个小练习
- 5 分钟：写入笔记

## 优先学习顺序

1. 间距和布局
2. 字体层级
3. 配色
4. 卡片/按钮/组件质感
5. 图片与图标
6. 动效
7. 响应式
8. 设计系统

## 纳斯执行承诺

以后遇到页面设计任务，我不只给建议，而是尽量做到：

- 直接改页面
- 直接截图验证
- 直接总结美化点
- 逐步沉淀自己的设计方法论
