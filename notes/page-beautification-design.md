# 页面美化与设计学习笔记

## 核心原则

1. 视觉层级
- 先让用户一眼看懂：标题 > 关键数据/行动 > 辅助说明。
- 用字号、字重、颜色、间距建立优先级，避免所有元素一样重。

2. 留白与间距
- 留白不是浪费，是高级感来源。
- 常用 8px 栅格：8 / 16 / 24 / 32 / 48 / 64。
- 卡片内部 padding 通常 16-32px，区块间距通常 32-80px。

3. 配色
- 主色 1 个，辅助色 1-2 个，中性色负责大面积背景与文字。
- 背景尽量低饱和，强调色只用在按钮、重点数据、状态提示。
- 深色模式要注意对比度，避免纯黑纯白刺眼。

4. 字体与排版
- 中文界面推荐：系统字体 / 思源黑体 / 阿里巴巴普惠体 / HarmonyOS Sans。
- 正文行高 1.5-1.8，标题行高 1.15-1.3。
- 一屏内字号层级不要太多：12 / 14 / 16 / 20 / 28 / 40 足够。

5. 卡片与组件
- 卡片用轻阴影、细边框、圆角、渐变背景提升质感。
- 圆角建议统一：8 / 12 / 16 / 24。
- 阴影要轻：大而淡，不要脏黑硬边。

6. 图片与图标
- 图标风格统一：线性/面性不要混用。
- 图片要有统一比例、裁切和色调。
- 可用半透明遮罩、模糊背景、渐变叠层增加氛围。

7. 动效
- 动效为理解服务，不为炫技。
- 常用：hover 微抬升、渐入、数字滚动、卡片 stagger。
- 时长一般 150-400ms，缓动用 ease-out / cubic-bezier。

## 快速美化检查清单

- 页面是否有明确主标题和主行动？
- 首屏是否过于拥挤？
- 色彩是否超过 3 个主视觉色？
- 字号、间距、圆角是否统一？
- 按钮是否足够明显？
- 内容是否被卡片/区块清晰分组？
- 是否有空状态、加载状态、错误状态？
- 移动端是否重新检查过？

## 常用风格方向

- 苹果风：大留白、柔和阴影、细腻渐变、克制文字。
- 科技风：深色背景、荧光强调、网格、玻璃拟态、粒子/光效。
- 商务风：蓝/灰/白、清晰栅格、数据卡片、稳重按钮。
- 年轻潮流：高饱和撞色、大标题、贴纸感、动态排版。
- 极简高级：黑白灰、强字体层级、少量强调色、高质量图片。

## 给纳斯自己的执行习惯

当杰斯要求“美化页面/设计页面/做得好看”时：
- 先判断业务目标和受众，再定风格。
- 优先调整布局、层级、间距，再处理颜色和动效。
- 不只说建议；如果有文件可改，直接改并验证截图。
- 交付时说明改了哪些视觉点，并给出下一步可优化方向。
