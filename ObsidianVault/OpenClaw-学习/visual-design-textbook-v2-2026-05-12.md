## 这本教材是干什么的？

简单说：**教你怎么用眼睛做设计判断。**

不背术语，不堆理论。每个概念都配图和例子，看完就能用在日报、PPT、文档排版和图片生成上。

**适用场景：** AI日报 · PPT · 飞书文档 · 海报 · 信息图 · 图片生成提示词

## 第一章：色彩 — 为什么有的配色好看，有的扎眼

### 一、颜色是什么？

颜色不是"好看"或"不好看"，而是**传递情绪和信息的工具**。

**三个基本属性：**

- **色相** — 什么颜色？红、蓝、绿……
- **明度** — 多亮多暗？
- **饱和度** — 多鲜艳多灰？

> 📌 **记住：** 新手最容易犯的错就是颜色太多、太艳、太均匀。好的设计往往用色克制。

### 二、色相环 — 颜色的"地图"

色相环把颜色按光谱排成一圈。理解了它，就理解了配色。

![色相环示意图](../images/color-wheel.png)

**核心规律：**

- **相邻颜色**（如蓝+绿）→ 和谐、舒服，但可能单调
- **互补颜色**（如红+绿、蓝+橙）→ 对比强烈、有冲击力
- **三角配色**（红+蓝+黄）→ 丰富、活泼，但难控制

### 三、实战配色公式

#### 公式1：60-30-10 法则（最经典、最安全）

这是设计师最常用的配色比例：

- **60% 主色** — 背景、大面积区域（通常用中性色）
- **30% 辅助色** — 次要元素、板块区分
- **10% 强调色** — 按钮、重点、CTA

![60-30-10配色示例](../images/60-30-10-color-rule.png)

> 💡 **例子：** 日报的白底（60%）+ 浅灰板块（30%）+ 蓝色重点词（10%）

#### 公式2：同色系渐变

选一个颜色，用它的深浅变化做层次。

- 安全、高级、不易出错
- 适合：品牌页面、PPT、专业报告

#### 公式3：互补色 + 中性色

选一对互补色，但只用其中一个做主色，另一个做点缀，其余用黑白灰。

- 有对比但不刺眼
- 适合：需要强调某个重点时

### 四、常见错误（一定要避免）

❌ **彩虹色** — 红橙黄绿蓝紫全用上 → 像幼儿园黑板报
❌ **高饱和撞色** — 亮红配亮绿 → 眼睛受不了
❌ **颜色太多** — 超过5种主要颜色 → 没有重点
❌ **忽略对比度** — 浅灰字配白底 → 看不清

### 五、配色实操步骤

1. **先定主色** — 根据场景选（科技用蓝、自然用绿、活力用橙）
2. **加中性色** — 白、灰、黑做背景和过渡
3. **选1个强调色** — 用于重点信息
4. **检查对比度** — 文字和背景要能看清
5. **限制颜色数量** — 主色+辅助色+强调色 ≤ 4种

### 六、参考

- Material Design 色彩系统：https://m3.material.io/color
- WCAG 对比度标准：https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum
- Adobe 配色工具：https://color.adobe.com

## 第二章：字体与排版 — 让文字自己说话

### 一、字体就是"声音的语调"

同样的文字，用不同字体呈现，给人的感觉完全不同：

> "今日AI重大新闻"
> - 用黑体 → 严肃、权威
> - 用圆体 → 友好、轻松
> - 用手写体 → 个人化、随意

**核心原则：字体要匹配内容的气质。**

### 二、字体层级 — 让读者知道先看什么

人眼不会平均看待所有文字。好的排版会**引导视线**。

**层级规则：**

| 层级 | 用途 | 字号比例 | 字重 |
|------|------|---------|------|
| 大标题 | 页面主题 | 2.0-3.0x | Bold/Heavy |
| 小标题 | 板块分区 | 1.5-1.8x | SemiBold |
| 正文 | 信息主体 | 1.0x（基准） | Regular |
| 注释 | 补充说明 | 0.8-0.9x | Regular/Light |

![字体层级对比图](../images/font-hierarchy.png)

> 📌 **关键：** 层级差异要**明显**。差一点点，读者就分不清。

### 三、中文排版的特殊规则

中文和英文排版不一样，有几点特别注意：

#### 1. 行距要够

- 英文：行距 1.4-1.6 倍
- **中文：行距 1.6-2.0 倍**（中文笔画密，需要更多呼吸空间）

![行距对比](../images/line-spacing.png)

#### 2. 段落要短

- 中文段落 **不要超过 5-6 行**
- 长了就换段，或者拆成列表

#### 3. 字重选择

- 小字号（<14px）不要用细体（Light/Thin）→ 看不清
- 正文用 Regular 最安全
- 标题用 Bold/SemiBold

#### 4. 字体数量

- **整篇文档 ≤ 2 种字体**
- 一种用于标题，一种用于正文
- 中文推荐：思源黑体、苹方、鸿蒙字体

### 四、加粗的正确用法

加粗不是强调的唯一方式，更不是随便用的：

✅ **加粗关键词** — 帮助扫读
✅ **加粗数据** — 让数字跳出来
❌ **加粗整段** — 没有重点就等于没有重点
❌ **加粗+斜体+下划线一起用** — 视觉噪音

### 五、对齐方式

- **左对齐** — 最易读，长文首选
- **居中对齐** — 适合短标题、封面、邀请卡
- **右对齐** — 少用，特殊场景（如引用署名）
- **两端对齐** — 中文慎用，会产生不均匀字间距

### 六、参考

- Apple 人机界面指南（排版部分）：https://developer.apple.com/design/human-interface-guidelines/typography
- Material Design 排版：https://m3.material.io/typography

## 第三章：构图与布局 — 东西放哪儿、放多少

### 一、什么是构图？

构图就是**在有限的空间里安排元素的位置和大小**。

不管是日报、PPT、海报还是网页，都要回答三个问题：

1. **什么东西最重要？** → 放最大、最显眼的位置
2. **读者怎么看？** → 按阅读顺序排列
3. **留多少空白？** → 空白不是浪费，是设计的一部分

### 二、网格系统 — 设计的骨架

网格不是限制创意，而是**让设计有条理**。

#### 常见网格类型：

**12列网格**（最常用）：

![12列网格示例](12列网格图)

- 网页、App、PPT 都适用
- 元素对齐到网格线上
- 内容区域占 8-12 列，两侧留白

#### 网格实操：

1. 先画网格（心里画也行）
2. 把重要内容放在网格交叉点附近
3. 元素边缘对齐网格线
4. 留出一致的间距

### 三、留白 — 设计的力量

**留白 = 呼吸空间 = 高级感**

新手最大的错误：把空间填满。

![留白对比图](../images/whitespace-comparison.png)

> 📌 **左图 vs 右图：** 同样的内容，右边留白多，看起来更专业、更易读。

**留白规则：**

- 标题上方留白 ≥ 标题下方留白
- 板块之间间距 ≥ 板块内部间距
- 页面边缘留白 ≥ 内容内部间距
- **宁可多空，不要挤满**

### 四、三分法构图

把画面分成 3×3 的九宫格，重要元素放在**交叉点**上。

![三分法示意图](../images/rule-of-thirds.png)

- 摄影、海报、PPT 封面都适用
- 比居中更有动感
- 交叉点天然吸引视线

### 五、视觉动线 — 引导读者的眼睛

人的阅读习惯是有规律的：

- **中文：从左到右、从上到下**
- **F型阅读** — 先看顶部，再看左侧，再扫中间
- **Z型阅读** — 首页/封面常用，四角+对角线

**设计时要顺应阅读习惯：**

- 最重要的信息放在左上/顶部
- 次要信息按阅读顺序排列
- CTA（行动号召）放在视线终点

### 六、参考

- Nielsen Norman Group（UX 布局）：https://www.nngroup.com
- Apple 布局指南：https://developer.apple.com/design/human-interface-guidelines/layout

## 第四章：设计系统 — 让设计保持一致

### 一、什么是设计系统？

设计系统就是一套**可重复使用的规则**，让所有输出看起来像一个团队做的。

包含：

- 颜色板（哪些颜色能用）
- 字体规则（什么场景用什么字体）
- 间距系统（元素之间隔多远）
- 组件库（按钮、卡片、标签长什么样）

### 二、为什么需要设计系统？

❌ **没有系统：** 每次设计都像第一次，风格乱跳
✅ **有系统：** 5分钟搭出一页好看的PPT，风格统一

### 三、间距系统 — 用数字管间距

不要"感觉差不多就行"，用**固定的间距值**。

**推荐间距刻度（基于4px）：**

| 间距名 | 值 | 用途 |
|--------|-----|------|
| xs | 4px | 文字内部间距 |
| sm | 8px | 相关元素之间 |
| md | 16px | 段落之间 |
| lg | 24px | 板块之间 |
| xl | 32px | 大板块之间 |
| xxl | 48px | 页面级间距 |

> 📌 **规则：** 间距只用这些值，不用随机数。

### 四、组件化思维

把常用视觉元素做成"组件"，重复使用：

- **新闻卡片** — 标题+摘要+标签
- **数据展示** — 大数字+说明文字
- **引用块** — 左侧边框+斜体文字
- **CTA按钮** — 强调色背景+白色文字

### 五、参考

- Material Design 组件库：https://m3.material.io/components
- Apple 设计系统：https://developer.apple.com/design
- Figma 社区设计系统：https://www.figma.com/community

## 第五章：图表与PPT叙事 — 把复杂变简单

### 一、好图表的标准

**3秒测试：** 读者3秒内能看懂什么信息？

- ✅ 能 → 好图表
- ❌ 不能 → 太复杂了，简化

### 二、图表选择指南

| 想表达什么 | 用什么图 |
|-----------|---------|
| 大小对比 | 柱状图 |
| 趋势变化 | 折线图 |
| 占比关系 | 饼图/环形图（≤5项） |
| 分布情况 | 散点图/直方图 |
| 流程关系 | 流程图 |
| 层级关系 | 树状图/组织图 |

### 三、PPT叙事的核心

PPT不是文档，是**视觉辅助讲故事的工具**。

**一页PPT的黄金法则：**

1. **一个观点** — 一页只说一件事
2. **标题就是结论** — 不要写"市场分析"，写"市场正在快速增长"
3. **视觉优先** — 图 > 表格 > 文字
4. **少即是多** — 能删的字都删
5. **数据可视化** — 数字放大、对比明显

### 四、前后对比

**差的PPT页面：**

> "2025年AI市场规模分析"
> （下面是一大段文字描述+复杂表格）

**好的PPT页面：**

> "AI市场2025年突破万亿美元"
> （一个大数字 ">$1万亿" + 一个上升趋势图 + 一行说明）

- Storytelling with Data：https://www.storytellingwithdata.com
- Google 数据可视化指南：https://developers.google.com/chart/interactive/docs/basic_gallery

## 第六章：纳斯视觉输出规范（拿来就用）

### 一、配色方案

| 角色 | 颜色 | 用途 |
|------|------|------|
| 主背景 | #FFFFFF / #0E0E10 | 白底（日间）/ 深黑（夜间） |
| 次要背景 | #F5F5F7 / #1A1A1E | 板块区分 |
| 主文字 | #1D1D1F / #F5F5F7 | 正文 |
| 次要文字 | #86868B / #A1A1A6 | 注释、日期 |
| 强调色 | #0071E3 | 链接、重点、CTA |
| 成功色 | #34C759 | 正向数据 |
| 警告色 | #FF9500 | 需要注意 |
| 危险色 | #FF3B30 | 问题、风险 |

### 二、字体规则

- **标题：** 思源黑体 Bold，2.0-2.5x 基准字号
- **小标题：** 思源黑体 SemiBold，1.5x
- **正文：** 思源黑体 Regular，16px 基准
- **注释：** 思源黑体 Regular，14px，灰色
- **行距：** 正文 1.8x，标题 1.3x
- **最多2种字体**

### 三、间距规则

- 标题上方：32px
- 标题下方：16px
- 段落之间：16px
- 板块之间：32px
- 页面边缘：24px

### 四、日报模板结构

```
┌─────────────────────────────┐
│  📅 日期 + 天气             │  ← 顶部信息条
├─────────────────────────────┤
│                             │
│  🎯 今日核心结论            │  ← 一句话概括
│  （加粗、放大）             │
│                             │
├─────────────────────────────┤
│  📰 新闻板块1               │
│  ┌─────────────────────┐   │
│  │ 🏷️ 标签 标题        │   │  ← 新闻卡片
│  │ 简短摘要...          │   │
│  └─────────────────────┘   │
│  ┌─────────────────────┐   │
│  │ 🏷️ 标签 标题        │   │
│  │ 简短摘要...          │   │
│  └─────────────────────┘   │
├─────────────────────────────┤
│  🔍 纳斯观察                │  ← 固定栏目
│  一句话洞察                 │
└─────────────────────────────┘
```

### 五、PPT模板规则

- 每页 ≤ 6 行文字
- 标题写成观点
- 数字放大 2-3 倍
- 图表 > 表格 > 文字
- 背景干净，不抢内容
- 页脚放日期和来源

## 附录：快速检查清单

每次视觉输出前，过一遍：

- [ ] 颜色 ≤ 4 种？
- [ ] 字体 ≤ 2 种？
- [ ] 有清晰的层级（大中小）？
- [ ] 留白够不够？
- [ ] 重点信息够不够突出？
- [ ] 段落够不够短？
- [ ] 3秒内能看懂主要内容？
