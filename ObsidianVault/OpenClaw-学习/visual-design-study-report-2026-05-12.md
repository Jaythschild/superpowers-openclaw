## 参考内容与链接

### 1. Apple Human Interface Guidelines

- Human Interface Guidelines 总入口  
  https://developer.apple.com/design/human-interface-guidelines  
  参考内容：设计基础、层级、和谐、一致性、平台设计原则。

- Typography  
  https://developer.apple.com/design/human-interface-guidelines/typography  
  参考内容：字体选择、可读性、动态字体、字重、字号、内容层级。

- Accessibility  
  https://developer.apple.com/design/human-interface-guidelines/accessibility  
  参考内容：颜色对比、文字可读性、不要只靠颜色表达信息、可访问性设计。

### 2. Material Design / Material 3

- Color system overview  
  https://m3.material.io/styles/color/system/overview  
  参考内容：颜色系统、色彩角色、主题色、界面语义。

- Color roles  
  https://m3.material.io/styles/color/roles  
  参考内容：primary、secondary、tertiary、surface、error、on-color 等颜色角色。

- Typography overview  
  https://m3.material.io/styles/typography/overview  
  参考内容：字体系统、阅读体验、字体层级。

- Type scale tokens  
  https://m3.material.io/styles/typography/type-scale-tokens  
  参考内容：display、headline、title、body、label 等字体层级 token。

- Layout overview  
  https://m3.material.io/foundations/layout/overview  
  参考内容：布局、网格、空间、响应式设计。

- Android Developers: Material Design 3 in Compose  
  https://developer.android.com/develop/ui/compose/designsystems/material3  
  参考内容：Material 3 色彩、字体、组件、主题系统在实现层面的应用。

### 3. Nielsen Norman Group

- Visual Design topic  
  https://www.nngroup.com/topic/visual-design/  
  参考内容：视觉设计研究、案例、视频集合。

- Good Visual Design, Explained  
  https://www.nngroup.com/articles/good-visual-design/  
  参考内容：网格、视觉层级、有意图的颜色、一致性。

- Visual Hierarchy video  
  https://www.nngroup.com/videos/visual-hierarchy/  
  参考内容：用颜色、大小、接近性、共同区域等建立视觉层级。

- Principles of Visual Design  
  https://www.nngroup.com/articles/principles-visual-design/  
  参考内容：scale、visual hierarchy、balance、contrast、Gestalt principles。

- 5 Visual-design Principles PDF  
  https://media.nngroup.com/media/articles/attachments/Principles_Visual_Design-Letter.pdf  
  参考内容：比例、层级、平衡、对比、格式塔原则。

### 4. W3C / WCAG

- WCAG 2.2  
  https://www.w3.org/TR/WCAG22/  
  参考内容：可访问性整体标准，可感知、可操作、可理解、稳健。

- Contrast Minimum  
  https://www.w3.org/TR/WCAG22/#contrast-minimum  
  参考内容：普通文字 4.5:1，大文字 3:1 的对比参考。

- Non-text Contrast  
  https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html  
  参考内容：UI 组件、关键图形至少 3:1 的非文本对比参考。

### 5. Figma Learn / Figma Help

- Introduction to design systems  
  https://help.figma.com/hc/en-us/articles/14552901442839-Overview-Introduction-to-design-systems  
  参考内容：设计系统的概念、价值和组成。

- Define your design system  
  https://help.figma.com/hc/en-us/articles/14552740206743-Lesson-2-Define-your-design-system

- Build your design system  
  https://help.figma.com/hc/en-us/articles/14548865734679-Lesson-3-Build-your-design-system

- Create Color, Text, Effect and Layout Grid Styles  
  https://help.figma.com/hc/en-us/articles/360038746534-Create-Color-Text-Effect-and-Layout-Grid-Styles  
  参考内容：颜色样式、文字样式、效果样式、网格样式。

- Typography systems in Figma  
  https://www.figma.com/best-practices/typography-systems-in-figma/  
  参考内容：字体系统、样式命名、层级管理。

- Typography in design  
  https://www.figma.com/resource-library/typography-in-design/  
  参考内容：字体在设计中的作用、阅读体验和风格表达。

- Consistency in design  
  https://www.figma.com/resource-library/consistency-in-design/

### 6. 数据可视化

## 本轮总结

本轮学习形成了一个可执行的视觉设计框架：

- 字体负责阅读秩序与内容气质。
- 色彩负责角色、状态、情绪和注意力。
- 排版负责结构、节奏和信息组织。
- 构图负责画面观看路径。
- 美术基础负责质感、空间、光影和比例判断。
- 设计系统负责长期一致性和复用。
- 图表与PPT叙事负责把信息转成观点和判断。
