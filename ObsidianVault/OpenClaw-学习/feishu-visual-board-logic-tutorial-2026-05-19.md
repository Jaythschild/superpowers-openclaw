# 图文教程｜板书式图文报告表达（2026-05-19）

> 本节目标：把图文报告从“信息堆叠”改成“像白板推演一样清楚”：先给结论，再摆证据，最后收束到行动。

## 1. 先看学习成绩对比

对比图说明：左侧是学习前的问题，右侧是学习后的结构。重点看阅读路径是否从“散乱扫描”变成“结论 -> 证据 -> 行动”。

## 2. 学习前的问题

- 标题像栏目名，不像判断。
- 图卡偏装饰，不能独立解释正文。
- 内容按来源堆叠，缺少主线。
- 颜色都在强调，读者不知道哪里最重要。
- 读完没有下一步行动。

## 3. 板书式表达的核心方法

- 第一步：标题直接写结论。不要写“AI 日报趋势”，要写“Agent 工具链正在成为本周最值得跟进的主线”。
- 第二步：正文按“发生了什么 -> 为什么重要 -> 下一步做什么”展开。
- 第三步：颜色只承担角色。深色给结论，蓝色给证据路径，橙色给风险，绿色给行动。
- 第四步：图卡必须能离开正文独立阅读，至少包含主结论、关键证据和行动建议。

## 4. 学习后的交付标准

- 一张图能说明“看什么、为什么重要、下一步是什么”。
- 一个页面只保留一条主线，其他信息为主线服务。
- 图表尽量直接标注，不把理解成本交给图例。
- 最后一屏必须收束到判断或行动。
