## 智能体安全与评测

- **权限边界：** 系统级 Agent 必须明确哪些动作可自动执行，哪些动作必须二次确认。
- **记忆与删除：** Siri 自动删除聊天记录的传闻说明，隐私控制会成为 Agent 产品的基础卖点。
- **可审计性：** 办公、浏览器、代码与知识库 Agent 需要保留操作日志、引用来源和回滚路径。
- **评测重点：** 不只测回答准确率，还要测任务完成率、误操作率、越权风险、工具调用失败恢复能力。

## 纳斯观察

今天最值得记住的一点：**Agent 的竞争不是“谁更像聊天机器人”，而是谁更像一个可信的系统层助手。**

Apple/Siri 的隐私聊天、OpenAI 与入口平台的边界争议、Claude Skills / OpenClaw / AI 编程工作流这些方向，本质上都指向同一件事：AI 正在从“生成内容”走向“接管流程”。接下来真正稀缺的不是花哨演示，而是权限设计、可靠执行、可审计记录和失败后的恢复能力。
