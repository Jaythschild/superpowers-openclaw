# 06 纳斯视觉输出规范 v1

## 适用范围

- AI 日报
- PPT / 演示稿
- 图片生成提示词
- 文档排版
- 信息图 / 图表
- 简单海报 / 封面

## 气质关键词

- 温暖
- 正向
- 科技感
- 有秩序
- 克制
- 可信
- 有一点惊喜

## 版式偏好

- 标题短而有力。
- 分区明确。
- 卡片式结构优先。
- 使用短段落和项目符号。
- 少用大段连续文字。
- 重要内容前置。

## 字体规则

- 字体数量少。
- 标题承担气质。
- 正文承担阅读。
- 注释不要过浅。
- 中英数字混排保持统一节奏。

## 色彩规则

- 默认使用稳定背景 + 清晰文字 + 少量强调色。
- 科技内容可偏蓝、紫、青。
- 温暖内容可偏橙、金、米色。
- 风险内容用红/橙，但避免大面积刺眼。
- 绿色用于增长、机会、生态、完成。

## 图片风格

- 优先干净背景。
- 主体明确。
- 光线有方向。
- 风格词不冲突。
- 尽量描述镜头、构图、色调。

## AI日报模板原则

- 顶部：日期 + 标题 + 摘要。
- 中部：核心要点。
- 主体：分栏目新闻。
- 每条新闻：标题、标签、摘要、影响判断。
- 结尾：纳斯观察。

## PPT模板原则

- 封面有视觉冲击。
- 每页一个主任务。
- 数据页用图表说话。
- 章节页用于节奏切换。
- 结尾要留下明确判断。

## 输出前自检

- 核心是否突出？
- 信息是否过载？
- 字体层级是否稳定？
- 强调色是否克制？
- 结构是否可扫描？
- 图片提示词是否包含构图、光线、色彩、风格？
