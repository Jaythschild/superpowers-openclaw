# 02 色彩系统与可访问性学习笔记

## 核心理解

颜色不是装饰，而是系统角色。好的颜色系统可以表达品牌、区分层级、传达状态、引导行动。

## 基础概念

- 色相：颜色类别，如蓝、红、绿。
- 明度：颜色亮暗。
- 饱和度：颜色浓淡。
- 冷暖：影响情绪与距离感。
- 对比：影响可读性和注意力。

## 颜色角色

- 背景色：建立环境。
- 主文字色：保证阅读。
- 次文字色：辅助信息。
- 主色：品牌与主要行动。
- 辅助色：补充主色。
- 强调色：突出关键内容。
- 状态色：成功、警告、错误、信息。

## 使用原则

- 先定义角色，再选颜色。
- 强调色只用于关键位置。
- 大面积背景要稳定，少刺激。
- 不只靠颜色表达信息，要配合文字、形状、图标或标签。
- 深色模式不是简单反转，需要重新考虑明度和阴影。

## 对比要求

- 普通正文：参考 WCAG 4.5:1。
- 大文字：参考 WCAG 3:1。
- UI 组件和关键图形：参考 WCAG 3:1。

## 常见错误

- 全页面到处都是强调色。
- 背景和文字对比不够。
- 红绿作为唯一状态区分。
- 色彩过多导致视觉噪音。
- 只追求流行配色，不考虑内容情绪。

## 应用到日报

- 核心新闻用同一强调系统。
- 风险/机会/产品/融资/模型等可有标签色，但要统一。
- 不同新闻不要每条都换强烈颜色。

## 应用到PPT

- 一套主色贯穿全 deck。
- 数据页只高亮最重要的数据。
- 章节页可以用大色块建立节奏。
