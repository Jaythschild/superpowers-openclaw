# OpenDesign 内容设计与课程统一风格系统（2026-05-19）

## 定位

OpenDesign 不只作为灵感来源，而是进入《设计、美学、排版、色彩、字体》的内容设计流程。后续课程、教程、日报、图文报告在生成前都要先经过统一的内容设计与视觉风格判断。

## 课程主风格

主风格采用 AI 科技风，但不能停留在黑底、蓝线、发光边框和文字堆叠。必须体现：

- 空间层次：有前景、中景、背景，信息模块不能平铺。
- 材质质感：玻璃、磨砂、冷光、精密网格只服务教学，不做廉价装饰。
- 信息秩序：主结论、证据、行动建议在视觉上有明确先后。
- 中文节奏：标题有判断，正文短句化，示例具体化。
- 交付一致性：教程、日报、PPT、飞书 Wiki 使用同一套结构和审美标准。

## OpenDesign 进入内容设计的方式

- 内容架构：先确定读者要学会什么，再决定章节、示例和练习。
- 视觉母版：每类内容先选版式母版，再生成图片或排版文档。
- 设计语言：参考 OpenDesign 的风格库，把风格命名、配色、字体、构图和动效原则转成可执行规范。
- 质量评审：生成后必须检查是否像系统课程，而不是像临时报告补丁。

## 当前课程适配的风格组合

- 主风格：Data Drift，用于 AI、机器学习、未来感、数据流和智能系统。
- 结构风格：Swiss Pulse，用于清晰网格、精密排版、指标和报告结构。
- 高级感约束：Velvet Standard，用于克制留白、少色彩、高级质感。

不采用 Maximalist Type、Folk Frequency、Deconstructed 作为主风格，除非主题明确需要强情绪、活动传播或反叛气质。

## 生成前设计流程

1. 先写内容目标：读者看完要理解什么、能做什么。
2. 选课程模块：视觉层级、中文排版、色彩系统、报告版式、信息图标注或交付验收。
3. 选风格组合：Data Drift + Swiss Pulse + Velvet Standard 为默认组合。
4. 写示例：每个知识点至少一个正例、一个反例或一个可执行场景。
5. 再生图或找图：图片必须解释知识点，不能只做背景。
6. 最后写入飞书：融合到体系位置，不把报告原文直接贴进去。

## 生成后检查清单

- 课程是否有统一风格，而不是每次新增都像补丁？
- 标题是否是判断句？
- 每个知识点是否有具体示例？
- 图片是否能独立解释一个概念？
- 配色是否克制且有信息角色？
- 字体层级是否清楚，中文是否可扫读？
- 是否应用到了教程、日报、飞书文档和图文报告？
- 是否删除了临时标题、测试图、空图片块和重复段落？
- 是否检查飞书文档写入结果，并确认图片 token 非空？

## 对日报、教程、文档的应用

- AI 日报：先做“今日主线 + 影响图卡 + 分栏目证据 + 纳斯观察”，再写新闻。
- 教程：先做“学习目标 + 概念 + 正反示例 + 操作步骤 + 练习 + 检查清单”。
- 飞书 Wiki：新增内容必须进入已有模块，不做孤立追加。
- 图文报告：图片不是装饰，必须承担解释、对比或流程说明。
