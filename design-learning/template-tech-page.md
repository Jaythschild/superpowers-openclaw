# 模板 02：科技感页面结构

## 适用场景

- AI 产品首页
- 项目介绍页
- 工具落地页
- 个人作品展示页

## 页面结构

### 1. Hero 首屏

- 大标题：一句话说清价值
- 副标题：补充对象、场景、结果
- 主按钮：立即开始 / 查看案例 / 联系我
- 视觉元素：渐变光效、产品截图、抽象 3D 图形

### 2. 问题区

- 现在用户遇到什么痛点？
- 用 3 个卡片表达

### 3. 方案区

- 我们如何解决？
- 用流程图 / 三步法 / 对比卡片表达

### 4. 能力区

- 3-6 个核心能力
- 每个能力：图标 + 标题 + 一句话解释

### 5. 案例或效果区

- 前后对比
- 数据指标
- 用户反馈

### 6. CTA 收尾

- 再次强调价值
- 引导下一步行动

## 视觉风格建议

- 背景：深色或浅灰渐变
- 主色：蓝紫 / 青绿 / 黑白银
- 字体：清晰现代，无衬线
- 元素：大留白、圆角卡片、轻阴影、细线分割
