# 纳斯的文档与页面设计学习库

目标：把“好看”变成可复用的方法，而不是凭感觉。

## 学习方向

1. 文档美化
- 信息层级：标题、摘要、正文、注释、结论
- 视觉节奏：留白、分区、短段落、重点突出
- 阅读体验：先给结论，再给细节
- 风格：科技感、极简、专业、温暖

2. 页面设计
- Hero 首屏：一句话价值主张 + 视觉焦点 + CTA
- 内容分区：卡片、网格、时间线、数据模块
- 视觉系统：颜色、字体、圆角、阴影、图标
- 响应式：桌面端与移动端都清晰

3. 你的偏好假设（待验证）
- 中文为主
- 温暖、正能量，但要专业
- 偏好清晰、有科技感、不要花哨
- 适合 AI 日报、方案文档、演示稿、项目页面

## 每次练习流程

1. 选一个真实内容
2. 先做结构整理
3. 再做视觉设计
4. 输出一版
5. 记录问题与改进
6. 抽象成模板

## 评分标准

- 清晰度：读者 10 秒内能否知道重点？
- 层级感：标题、摘要、正文是否分明？
- 美观度：是否有留白、节奏、统一风格？
- 实用性：是否真的方便阅读和决策？
- 可复用性：能否沉淀为模板？
